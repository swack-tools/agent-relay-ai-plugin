Zero-daemon-lock-in architecture

One stdlib Python script,
native hooks in every client

plugins/agent-relay/scripts/relay.py runs on Python 3.9+ using only the standard library—so sending a message to a remote computer streams the script over ssh HOST python3 - with nothing extra to install.

When a session runs on a target machine, client-native hooks and extensions register its address, wake idle sessions, and frame incoming peer messages as coming from another agent rather than the user.

Three steps to cross-agent relay

  1. Install Agent Relay in Antigravity, Claude Code, Codex, opencode, or pi.
  2. Restart open sessions so lifecycle hooks register each conversation.
  3. Open Relay Map or ask your agent to message a peer session.
