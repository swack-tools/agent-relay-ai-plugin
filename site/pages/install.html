Setup & multi-host SSH

Install in your coding client

Install Agent Relay on every computer whose sessions should receive messages. To only send from one computer to another, key-based ssh and python3 3.9+ on the target are enough.

Requirements Antigravity Claude Code Claude Desktop Codex CLI & Desktop opencode pi Multi-host SSH Release archives

Requirements

  • Python 3.9 or newer on every computer involved (all scripts and the MCP server use only the Python standard library).
  • Key-based ssh between computers (ssh <alias> true with no prompt) in each direction you want replies to travel.
  • Target client running: Codex app/CLI (shared daemon), Claude Code (hooks installed), Antigravity (app/IDE/CLI), opencode (background service), or pi (extension loaded).

Antigravity (app, IDE & agy CLI)

agy plugin install https://github.com/swack-tools/agent-relay-ai-plugin
agy plugin enable agent-relay

Open Agent Relay from the left sidebar under Plugins, open Relay Map from the side pane + menu, or invoke /relay-map, /list-sessions, /message-session, /handle-relay-message, and /relay-setup.

Claude Code

claude plugin marketplace add swack-tools/agent-relay-ai-plugin
claude plugin install agent-relay@agent-relay

Restart open Claude Code sessions afterwards so the SessionStart hook registers each session and starts the idle wake-up watcher. Invoke /agent-relay:relay-map or /agent-relay:message-session.

Claude Desktop

Open Customize → Plugins → Add → Add marketplace → Add from GitHub, enter swack-tools/agent-relay-ai-plugin (or swack-tools/ai-plugin-marketplace), and install Agent Relay. You can also upload agent-relay-claude.zip or agent-relay-<version>.plugin from the verified releases.

Codex CLI & Desktop

codex plugin marketplace add swack-tools/agent-relay-ai-plugin
codex plugin add agent-relay@agent-relay

Open codex and press t to review and trust the plugin's hooks. Invoke $relay-map, $list-sessions, $message-session, or $relay-setup. Messages reach Codex through codex queue on the shared app-server daemon.

opencode

opencode plugin add 'github:swack-tools/agent-relay-ai-plugin#main::path:plugins/agent-relay'

From a local clone, add the path to plugins in ~/.config/opencode/opencode.json. Messages reach opencode sessions through the opencode background service via opencode api session.prompt.

pi

pi install git:github.com/swack-tools/agent-relay-ai-plugin

Restart open pi sessions (or run /reload) to load the TypeScript extension, which registers each session and polls the mailbox every two seconds to wake idle sessions.

Multi-host SSH & doctor check

Define clean aliases in ~/.ssh/config for each computer, then verify connectivity and PATH discovery:

python3 <plugin-folder>/scripts/relay.py doctor
python3 <plugin-folder>/scripts/relay.py doctor --host laptop
python3 <plugin-folder>/scripts/relay.py sessions --host laptop

Remote sends stream scripts/relay.py directly into ssh HOST python3 -, so no remote plugin checkout is required just to send.

Verified release archives

Tagged releases publish deterministic client archives (agent-relay-claude.zip, agent-relay-codex.zip, agent-relay-<version>.zip, and .plugin) with a verified SHA256SUMS manifest:

gh release download --repo swack-tools/agent-relay-ai-plugin --pattern '*.zip' --pattern 'SHA256SUMS'
shasum -a 256 -c SHA256SUMS --ignore-missing
