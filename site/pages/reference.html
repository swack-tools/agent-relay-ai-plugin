relay MCP server tools

plugins/agent-relay/scripts/relay_mcp_server.py runs as a Python 3.9+ stdlib stdio JSON-RPC 2.0 server serving ui://agent-relay/relay-map.html alongside 7 model-visible tools and 2 app-only UI tools (relay_map_poll, relay_map_prefs):

ToolTitleBehavior
relay_mapOpen Relay Map dashboardReturns fleet summary and renders ui://agent-relay/relay-map.html (supports filter, tab, focus_agent, and lookback_hours).
relay_sessionsList live agent sessionsLists live sessions across all 5 clients locally or on an ssh host.
relay_sendSend relayed messageRoutes a message or file to a target address, optionally waiting for a reply.
relay_inboxInspect session inboxReads or peeks pending messages in a local Claude Code or pi mailbox.
relay_read_replyRead recent agent repliesReads recent assistant turns from a Claude, Codex, Antigravity, opencode, or pi session.
relay_broadcastBroadcast to agentsPreviews (dry_run=true) or sends a broadcast to all agents, a pool, or a host.
relay_transcriptRead session transcriptReturns flattened conversation turns or raw JSONL tail from a recorded session transcript.

Package & state layout

  • Canonical plugin: plugins/agent-relay/ contains .antigravity-plugin/, .claude-plugin/, .codex-plugin/, skills/, hooks/, scripts/, opencode/, pi/, and assets/relay-map.html.
  • Local state: ~/.agent-relay/ stores registered sessions, inbox/, outbox/, relay-map-prefs.json, and 0600 cached Antigravity language server tokens (override with AGENT_RELAY_HOME).
  • Catalog & API metadata: catalog-info.json and api/agent-relay/tools.json describe capabilities for the Swack Tools Marketplace.
