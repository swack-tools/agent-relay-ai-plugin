Peer-agent framing & trust boundaries

  • Peer origin markers: Relayed messages are explicitly framed as coming from a peer AI session—never spoofed as user instructions. Bundled skills require bringing risky or out-of-scope requests back to the user.
  • Owner-only local state: ~/.agent-relay/ directories and cached Antigravity language server tokens are created with 0600 permissions; CSRF tokens are never printed or logged.
  • Zero external telemetry: Messages travel only over local sockets, owner-only files, and your own ssh connections.

Standalone Rust/WASM hub & Kubernetes deployment

For teams or multi-workstation setups that want an always-on web dashboard, web-ui/ builds the Rust relay-map Axum server and WASM frontend, complete with Kustomize manifests in web-ui/deploy/k8s/ for Envoy Gateway + SSH tailing.

cargo build --release --manifest-path web-ui/Cargo.toml
./web-ui/deploy/k8s/build-image.sh
kubectl apply -k web-ui/deploy/k8s/example

See web-ui/deploy/k8s/README.md on GitHub ↗ for SSH key secret setup, pool isolation config, and Envoy routing details.
